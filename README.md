# My Homepage

A simple personal homepage built with HTML and CSS.

## 🌐 How to Make This Repository Public

To change this repository from private to public on GitHub, follow these steps:

### Step 1: Go to Repository Settings
1. Navigate to your repository on GitHub: https://github.com/kianabahramian/my-homepage
2. Click on the **Settings** tab (you'll see it in the top menu bar of your repository)

### Step 2: Change Visibility
1. Scroll down to the **Danger Zone** section at the bottom of the Settings page
2. Click on **Change repository visibility**
3. Select **Make public**
4. GitHub will ask you to confirm by typing the repository name
5. Type `kianabahramian/my-homepage` to confirm
6. Click **I understand, change repository visibility**

### Important Notes:
- ⚠️ **Warning**: Once a repository is made public, anyone on the internet can see your code
- Make sure you don't have any sensitive information (API keys, passwords, personal data) in your code before making it public
- Your commit history will also be visible to everyone
- You can always change it back to private later if needed

## 🚀 Viewing Your Homepage

Once your repository is public, you can enable GitHub Pages to host your homepage:

### Enable GitHub Pages:
1. Go to **Settings** → **Pages** (in the left sidebar)
2. Under **Source**, select the branch you want to deploy (usually `main`)
3. Click **Save**
4. Your site will be published at: `https://kianabahramian.github.io/my-homepage/`
